# Cyberbulling Concept — Interactive Movie (PixiJS 8)

Интерактивный фильм по сценарию выпуска №14 «Хроники Продакшен-Ковчега» (V13).
Стек: PixiJS 8.21, TypeScript 5.6, Vite 8, @playbox-ai/playable-kit.

## Быстрый запуск
- Dev-сервер: `npm run dev` (порт 5174) или запустить `START_MOVIE_DEV.bat`
- Сборка single-file: `npm run build` (на выходе `dist/index.html`)
- Проверка типов: `npm run typecheck`

## Архитектура
- `src/main.ts` — точка входа, подключение SDK Playbox (`plbx.init`, `plbx.start()`), тикер и ресайз
- `src/MovieApp.ts` — оркестратор интерактивного фильма: кинематографичное интро PlayBox, переключение актов (Назад/Вперёд), управление озвучкой Илорды, прогресс-бар, таймлайн
- `src/CosmicScene.ts` — процедурная космическая сцена (дрейф звезд, туманности, анимация крейсера-ковчега)
- `src/Subtitles.ts` — компонент субтитров:
  - Режим без рамки: плавный полупрозрачный кинематографичный бар
  - Режим с рамкой: специальный высокотехнологичный терминал для сцен на троне и песни
  - Typewriter-эффект: посимвольное заполнение строк с мигающим курсором
- `src/storyData.ts` — полный сценарий: Вступление, Пролог, Акты 1–5, Награды (на троне), Песня, Аутро
- `src/AudioController.ts` & `src/ClickTracker.ts` — интеграция с Playbox SDK для рекламы и звука
- `src/assetsManager.ts` — пакетная загрузка текстур и аудиодорожек через Vite glob-импорты
