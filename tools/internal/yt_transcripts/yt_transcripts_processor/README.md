# YouTube Transcripts & LLM Warhammer 40,000 Lore Editor

Скрипт для автоматического сбора транскриптов видео с любого YouTube-канала, их разбивки на чанки (с учетом лимитов токенов) и литературной редактуры через OpenAI API (`gpt-4o-mini`).

## 📁 Структура директории

```
yt_transcripts_processor/
├── app.py               # Главный исполняемый скрипт
├── requirements.txt     # Зависимости проекта
├── .env.example         # Пример конфигурационного файла с ключами
├── .env                 # Ваш рабочий файл с API-ключами (создается вами)
└── README.md            # Инструкция
```

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.9+ и выполните команду в терминале:

```bash
pip install -r requirements.txt
```

### 2. Настройка API-ключа OpenAI
Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите ваш ключ:
```env
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxx
OPENAI_MODEL=gpt-4o-mini
```

> **Примечание:** Если вы используете прокси-шлюз или альтернативный совместимый API (например, OpenRouter), вы можете раскомментировать и указать строку:
> `OPENAI_BASE_URL=https://openrouter.ai/api/v1`

## ⚙️ Запуск скрипта

### Базовый запуск (канал по умолчанию):
```bash
python app.py
```

### Запуск с указанием конкретного канала:
```bash
python app.py --channel "https://www.youtube.com/@Voices_of_Imperium"
```

Или по handle / ID:
```bash
python app.py --channel "@Voices_of_Imperium"
```

### Тестовый запуск на первых 2-3 видео:
```bash
python app.py --channel "@Voices_of_Imperium" --max-videos 3
```

### Смена модели LLM и папки сохранения:
```bash
python app.py --channel "@Voices_of_Imperium" --model "gpt-4o" --output "my_channel_lore"
```

## 💡 Особенности реализации:
- **Обработка ошибок**: видео без субтитров не ломают процесс, скрипт выводит предупреждение и продолжает работу.
- **Кэширование**: если файл для видео уже был скачан и обработан ранее, он пропускается.
- **Чанкирование**: длинные часовые видео разбиваются на логические блоки по словам, чтобы не превышать лимиты контекстного окна.
- **Прогресс-бар**: наглядный вывод в терминале через `tqdm` со статусами.
- **Безопасные имена**: очистка от спецсимволов ОС (`/ \ : * ? " < > |`).
