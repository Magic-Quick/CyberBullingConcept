# Контент интерактива: пародии на телеигры

**Пробная вставка перед третьим актом:** [открыть «Проверку протокола»](protocol-preview/interactive-preview.html). Короткий вопрос с контекстом Slack и восемь синих ячеек. Ввод прямо в клетки: одна буква + Enter или всё слово + Enter, без переключателей. Правильная буква перемещается на свои места. Подключены игровые звуки и восемь реплик Geremy с иронией над мудростью руководителя; музыка раздумий играет по кругу до сюжета. После разгадки — кнопка продолжения; после трёх ошибок — реплика Лорда и автоматический переход. Сценарий и условия: `docs/guardians_edition/INTERACTIVE_PREACT_PROTOCOL.md`.

Набор от 15 ноября 2026 года. 16 ноября оформление «Поля чудес» заменено по уточнению пользователя на классические синие квадраты с серебристой рамкой и белыми буквами, как в передаче с Якубовичем. Открыть [`index.html`](index.html) в браузере: предпросмотр табло, вопроса с четырьмя ответами, таймера ЧГК и вся аудиобиблиотека. Работает напрямую с диска, без сборки и внешних библиотек.

## Как использовать графику

**Поле чудес.** Повторять `pole_chudes/graphics/tile_blank_cutout.png` по числу букв. Исходная ячейка имеет размер 77×73 пикселя: синяя поверхность, серебристая рамка. При открытии накладывать белую букву отдельным текстовым слоем; рекомендуемый шрифт — Times New Roman. Закрытые ячейки остаются синими без символа. Параметры — `pole_chudes/graphics/layout.json`. Для крупного экрана лучше `tile_blank.svg` / `tile_closed.svg`: они воссозданы вручную и масштабируются без потери чёткости. Референс: `references/yakubovich_blue_rbc.webp`.

**Миллионер.** `millionaire/graphics/quiz_overlay_blank.png` — прозрачная сборка 1024×200 с вопросом и четырьмя ответами. Текста в ней нет. Прямоугольники под текст, положение плашек и ключи A/B/C/D указаны в `graphics/layout.json`. Для отдельных компонентов использовать `question_blank_cutout.png` и `answer_blank_cutout.png`; для подсветки — `answer_selected.png`, `answer_correct.png`, `answer_wrong.png`. Сохранены также сырые вырезки до очистки текста. В SVG-версиях рамки реконструированы вручную.

**ЧГК.** `timer_ring.svg` и `question_panel.svg` — самостоятельные функциональные шаблоны проекта, **не вырезки оригинального экранного таймера передачи**. Число секунд и вопрос накладываются отдельным текстом. Из исторического фото вырезан только стол для референса.

## Последовательности звуков

- **Поле чудес:** заставка → барабан → ожидание буквы → верная / неверная буква → отгаданное слово. Для суперигры есть оригинальный фон ожидания примерно на 60 секунд.
- **Миллионер:** заставка → фон вопроса → фиксация выбора → правильный / неправильный ответ. Есть отдельные подложки более сложных вопросов, 50:50, звонок другу и окончание времени.
- **ЧГК:** заставка / волчок → вопрос → короткий сигнал начала минуты → обсуждение → предупреждающий сигнал → сигнал конца минуты **или** гонг → ввод ответа. Обсуждение можно проводить в тишине: фон в него не подмешан автоматически.

В предпросмотре ЧГК по умолчанию 60 секунд. Поле ответа до финального сигнала заблокировано и открывается при его запуске. В настройках доступны 5–180 секунд и выбор финального сигнала. «Сбросить» отменяет отсчёт и снова закрывает ввод. Страница служит локальным предпросмотром; ответы не отправляются и не сохраняются.

## Воспроизведение набора

Из корня проекта:

```powershell
python -X utf8 tools/interactive/collect_tv_quiz_assets.py
python -X utf8 tools/interactive/build_tv_quiz_graphics.py
```

Только графика «Поля чудес», без перезаписи остальных игр: `python -X utf8 tools/interactive/build_tv_quiz_graphics.py --show pole_chudes`.

Сборщик аудио повторно использует уже скачанные файлы. Вся обработка выполняется в `media/interactive`; `Fin` не используется. Сборка основного фильма и его сценарий не изменены.
