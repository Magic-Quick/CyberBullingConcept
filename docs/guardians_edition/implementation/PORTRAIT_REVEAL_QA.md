# Проверка 27 представлений персонажей

18.11.2026. Проверены 27 меток `[ПЕРСОНАЖ]` V15.1 и соответствующие кадры импортированного проекта. Просмотрены контактные листы, исходные кадры с подозрительным реквизитом и итоговые производные. Речь, сценарий, `default-project.md` и текущая генерация озвучки не менялись.

Главный дефект: часть «портретов» уже показывает предмет будущей истории. Это не разрешается исключением для идентификации человека. Дополнительно два повторных представления используют известный, но не относящийся к текущей сцене предмет.

Подготовлены **8 производных изображений**: 7 нейтральных портретов из существующего арта и композиция двух этих же портретов. Рекомендуются **11 замен кадров**, покрывающие 12 карточек. Лица не генерировались, люди не переносились в выдуманные события: выполнены только кроп, масштабирование с сохранением пропорций и нейтральное тёмное паспарту 16:9. Исходные файлы сохранены; в `Fin` ничего не записано.

Файлы: `media/visual/generated/Gui/neutral-portraits/`. Манифест: `media/interactive/chronicles/neutral-portraits.json`. В нём есть `portraits`, `frameOverrides` по стабильным ID кадров, исходные пути/хеши/кропы и `fullSourceAllowedFrom` — конкретные словесные якоря, после которых полный исходник уже допустим. Эти якоря дают разрешённую нижнюю границу, но не требуют насильно показывать каждый полный кадр.
