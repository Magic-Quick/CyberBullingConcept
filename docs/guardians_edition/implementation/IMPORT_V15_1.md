# Импорт V15.1 в монтажный проект

Реализовано 18.11.2026. Исходные V15/V15.1 не изменяются. Импортёр: `tools/chronicles/import_project.py`; проверка: `python -m unittest discover -s tools/chronicles -p test_import_project.py -v`.

Результат — `repo/src/chronicles/default-project.md`: речь в отдельных ID-блоках, ссылки на события и одна секция `chronicles-config`. В JSON не хранится вторая копия произносимого текста. Исходные свободные постановочные заметки остаются отдельным непроизносимым разделом для проверки человеком.

Проверено полное совпадение произносимого текста импортированной V15.1 с авторской V15: 107 явных блоков и вся обычная проза между ними; токены и пунктуация одинаковы. В режиссёрской нарезке получаются 242 реплики: 107 исходных ID и 135 фрагментов обычного рассказа. Фрагментация не добавляет и не удаляет слова.

Маршрут содержит пролог/интро, пять остановок в согласованном порядке, общие продолжения, пять залов, вердикт, эпилог и две экранные директивы. Реакции и COMMON не попадают в линейное воспроизведение. Готовая песня из старого фильма сохранена отдельным дополнительным узлом с существующей записью и субтитрами, без задания на новую озвучку.

Все 155 музыкальных/SFX-команд представлены клипами. Внутренние смены кадров привязаны к границам слов конкретной реплики; закрытие после последнего слова — к её концу. WAIT привязан к концу последней читаемой реплики вступления игры. Время отсутствующих записей равно нулю; производственные секунды не оцениваются по числу слов.

Перед идентификацией персонажа — три секунды чистого портрета и три секунды чтения карточки. Два человека, введённые одной репликой, получают последовательные представления. Для заведомо спойлерных портретов с Disney/хирургией/ачивкой использован доступный нейтральный аватар соответствующего человека; исходный замысел сохранён в заметках. Метрики из заголовков, которые могли заранее раскрыть цифры/панчлайны, оставлены отдельными отключёнными клипами до назначения точных моментов раскрытия в режиссёре.

Голосовая ведомость: `media/interactive/chronicles/voice-manifest.json`. Исходный результат — 35 привязок к 31 существующему клипу, 207 реплик для проверки библиотеки/дозаписи. Два из переиспользований отличаются только типографическим многоточием. Импортёр подхватывает `generated-voice.json` с готовыми записями и реальным выравниванием слов; повторный импорт пересчитывает зависимые интервалы.

Импортёр не генерирует изображения и аудио, не обращается к внешним API и не записывает файлы в `Fin`. Пять игровых контекстов подключаются только из реально существующих подготовленных файлов, перечисленных в `media/interactive/chronicles/context-assets.json`; оригинальные скриншоты не выдаются за маскированные. Для каждого контекста создан редактируемый клип V2: в ЧГК — на слове «внимание» в контексте, в остальных играх — после последней вступительной реплики. Копия Househunt честно остаётся допустимым нейтральным портретом, а пятая игра использует реальную расшифровку синка.
