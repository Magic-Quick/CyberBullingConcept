# Проверка переноса V15.1 — 18.11.2026

Проверялся текущий `game.html`, совпадающий с `repo/dist/index.html`. Адрес текущей версии: `http://127.0.0.1:8877/game.html`. `game-v2-before-director.html` — только исходный образец до переноса, в нём нет пяти новых остановок. В процессе сравнения он был ошибочно оставлен на экране; после замечания пользователя вкладка закрыта и заменена текущим фильмом.

Дизайн обычного плеера возвращён к исходной консоли WS-96. Используются прежние текстуры, геометрия, кнопки, ручки, LCD, наклейки и точечные главы. Верхняя служебная панель и новая большая двухрядная панель в зрительском режиме скрыты. Две маленькие метки остановки встроены в прежнюю шкалу. Полный монтажный интерфейс открывается отдельно.

Повторная проверка Co-Writer API подтвердила открытый V15.1 без несохранённых изменений, contentHash `b6eaf892b95e95f3ffea04c5fbca37b02c20ca6cd7c19645060e31b314cefa4a`. Первые абзацы совпадают с голосовыми блоками проекта. Независимый тест сравнивает весь поток речи с V15, включая 135 обычных абзацев и 107 явных реплик. Исходные документы не менялись.

Проверено в настоящем браузере:

- Передача слова → ожидание команды → игровая подводка, без таймера живого выступления.
- I-04: три различные ошибки, недоступность выбранного неверного варианта, COMMON и автоматический выход в общую историю; отдельно верный ответ и кнопка возврата.
- I-01: полный ответ из восьми букв, озвученная реакция и переход в зал II.
- I-03: единственный неверный содержательный ответ, раскрытие и переход в общее продолжение без второй попытки.
- I-02: выбор B, удаление всех четырёх пунктов перед раскрытием, единое продолжение IV.
- I-05: первая буква П, затем оставшиеся четыре буквы, победа и выход из игры.
- Маскированный контекст остаётся при игровых реакциях и убирается в сюжете, включая COMMON из другой сцены.
- Кнопки исходной WS-96: переходы фраз, CC, mute и вход в режиссёрский режим. Ошибок в консоли браузера на итоговом проходе нет.
- Монтаж: непрозрачность кадра `.99` сохранена сервером; после перезагрузки инспектор и реальный экран восстановили `.99`. Затем возвращено `1` и снова подтверждена запись файла.

Ускоренный проход использовал переходы по записанным фразам и явные игровые действия; фильм целиком в реальном времени для этих проверок не ожидался.
