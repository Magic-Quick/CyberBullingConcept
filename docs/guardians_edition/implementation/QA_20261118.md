## Повторная проверка регрессий зрительского плеера

Проверен основной `http://127.0.0.1:8877/game.html?v=viewer-fix-20261118`, после производственной сборки, а не сохранённый HTML старого движка. Кандидат закрыт, основная вкладка оставлена перед единственной активной кнопкой «Начать просмотр». Ошибок/предупреждений консоли браузера на итоговом проходе нет.

Подтверждены:

- Исходные дисклеймер, звёздное видео, логотипы и титр; тайминг и типографика извлечены из MovieApp. Проверены пауза в заставке, P, 0–9 и переход PageDown в новый текст.
- K / Space, J/L, стрелки ±5 секунд, Shift+стрелки / PageUp / PageDown; M, C и D. Для букв добавлено распознавание физических клавиш русской раскладки. Модификаторы Ctrl/Meta не перехватываются зрительским обработчиком.
- Настоящая кнопка Play запускает запись: индикатор прогресса с 300 вырос до 340; повторное нажатие останавливает её. Проверен слайдер музыки 5000 → 2500 → 5000.
- F и настоящий двойной щелчок мышью устанавливают полноэкранное состояние, повторный F снимает. Проверка по реальному `aria-pressed` кнопки, обновляемому от браузера. Синтетический DOM double-click без доверенного пользовательского ввода для этой проверки не использовался.
- Наклейка заставки возвращает дисклеймер; «Высшая милость» перематывает к началу VERDICT.P012, а не к началу общего вердикта.
- Передача слова → только «Продолжить» → озвученное вступление I-04 → варианты. D выбирает вариант D и не открывает монтаж. Ускоренный проход использует явную перемотку текущей ветки, без ожидания человеческого темпа.
- T/P/X в режиссёре создают правильные cue/команду остановки. ] и [ меняют начало 4,8 → 5,8 → 4,8. Все пять проверочных изменений отменены через Ctrl+Z. Ctrl+S получил серверное подтверждение; затем основной мастер дополнен только адресами навигации и пересобран.
- Буква K в поисковом поле вводится в поле и не запускает воспроизведение. Новая вкладка «Музыка» показывает оба варианта интро, прежние банки cue и выбор оптического перехода/звука.

Офлайн ASR проверил все 207 новых MP3 по хешам текущего кеша. Исправлены HANDOFF-01, I-04.ВХОД, PROLOGUE.P018, ROOM-II.P008, VERDICT.P005, ROOM-I.P012. Оставшиеся три автоматических флага относятся к распознаванию имён, англицизмов и составных слов; распознанные строки и различия сохранены для проверки. Это не утверждение о полном прослушивании каждой записи человеком.

Подтверждающие кадры: `scratch/chronicles-viewer-regression/main-start.jpg`, `opening-disclaimer.jpg`, `main-opening.jpg`, `main-player.jpg`, `host-only-continue.jpg`. Итоговый мастер: 28 сцен, 923 клипа, 242 речевых блока / 3587 слов и пять остановок. Основной HTML совпадает с `repo/dist/index.html`; V1/V2 архивы не менялись.
