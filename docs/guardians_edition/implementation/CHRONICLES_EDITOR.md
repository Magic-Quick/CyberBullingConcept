# Хроники: фильм и режиссёрский монтаж

Реализовано 18.11.2026 на основе V15.1. Предыдущий код и материалы сохранены в GitHub: ветка `codex/backup-before-director-plan-20261118`, коммит `f11664f46abd1bc26a24d383a60600a63d53dd80`.

## Запуск

1. Из корня проекта запустить `tools/OPEN_CHRONICLES_DIRECTOR.bat`.
2. Редактор: <http://127.0.0.1:8877/repo/dist/index.html?director>. Просмотр: <http://127.0.0.1:8877/game.html>. В просмотре клавиша D/В или надпись WS-96 открывает режиссёра.
3. Выбрать сцену и при необходимости игровую ветку. Центральный экран использует тот же рендер, что фильм.
4. Сохранить через Ctrl+S. Надпись об успешной записи появляется только после подтверждения файла сервером.

Основной текстовый файл — `repo/src/chronicles/default-project.md`. Речь хранится один раз в блоках `[ГОЛОС ЛОРДА ID]`; единственная секция `chronicles-config` хранит ресурсы, дорожки, клипы, привязки, остановки, правила и ветки. Обычный Markdown до конфига остаётся читаемым сценарием. Редактор умеет открыть, применить и экспортировать весь Markdown.

При конфликте с внешним редактором запись отклоняется по версии. Сервер не перезаписывает чужие изменения. Если этот же файл открыт в Co-Writer, запись идёт через Hub API с `expectedVersion`, проверкой `editorVerified` и отдельным сохранением. История прежних файлов хранится в `scratch/chronicles-history/`.

## Монтаж

Доступны библиотека с поиском, предпросмотром и перетаскиванием, 12 дорожек, инспектор, выбор веток, масштаб и магнит, перемещение и обрезка клипов, сдвиг последующих клипов, несколько выделенных клипов, копирование, вставка, дубликат, удаление, undo/redo. На экране можно перетащить видимый объект; точные значения задаются справа.

- V1: кадр, положение, масштаб, поворот, прозрачность, кроп, fade и чистая экспозиция.
- V2: скриншот или другое изображение с отдельным началом и концом.
- V3/V4: имя, полный титул и экранный текст.
- T1: субтитры от речи либо отдельная редакция.
- A1–A6: голос, атмосфера, нагнетание, передышка, музыка игры и SFX; громкость, fade, source in/out, петля, огибающая и приглушение BASE.
- I1: остановки, маршрут, тема живого слова, вопрос, ответы, лимиты, реплики и переходы игры.

Space / K управляют воспроизведением вне текстового ввода. J/L — ±10 секунд, ←/→ — ±5 секунд, Shift+←/→ и PageUp/PageDown — главы, 0–9 — процент текущей сцены, M — звук, C — субтитры, F — полный экран, D/В — режиссёр. Щелчок по кадру — Play/Pause, двойной — полный экран. На паузе и при движении мыши исходная консоль видна; при просмотре скрывается после 2,5 секунды. Ctrl+Z / Ctrl+Shift+Z — история. Речь редактируется в инспекторе: изменённый текст сразу помечает старую озвучку и словесные привязки устаревшими. Новая озвучка не генерируется без отдельного запуска пайплайна.

Якорь клипа может ссылаться на сцену, начало/конец реплики или конкретное выровненное слово. Сдвиг хранится рядом с якорем. Пауза останавливает монтажные часы; перемотка вычисляет слои заново. Чистая экспозиция кадра задаётся полем `cleanExposure`: плашки и скриншоты не закрывают его раньше указанного времени.

Библиотека использует ресурсы сборки. При добавлении новых файлов на диск их нужно включить в реестр ресурсов и пересобрать фильм; импорт Markdown сам по себе не копирует медиа на другой компьютер.

## Интерактивы и маршрут

Зрительский дизайн сохранён: исходная консоль WS-96, её текстуры, кнопки, ручки, LCD, тонкая шкала и наклейки. На ней у каждого из пяти залов две маленькие нейтральные метки: квадрат «Слово Толе» и ромб «Интерактив». Они показывают текущий этап, ожидание, прохождение и пропуск без названий ответов и сюжетных развязок. Живое слово и ответ зрителя ждут команды без фиктивной длительности и таймера поражения. Время шкалы относится к записанным главам; ожидание не растягивает шкалу.

I-04: четыре варианта и три различные ошибки. I-01: восемь букв. I-03: один окончательный содержательный ответ. I-02: один выбор и раскрытие всех четырёх пунктов. I-05: пять букв. COMMON.ЛИМИТ доступен только I-04/I-01/I-05. После реакции игра возвращается в единую историю. Маскированный контекст живёт на V2 до выхода в сюжет; увеличение открывает тот же подготовленный файл.

## Данные и сборка

Текущий мастер включает 242 речевых блока, 28 сцен, пять остановок и отдельный готовый музыкальный трек. 35 реплик использовали существующие записи, 207 озвучены Geremy через ElevenLabs с разрешения пользователя. Все 3587 слов имеют реальные временные границы; недостающие метаданные восстановлены локально без повторной генерации. В отчётах выравнивания сохранены показатели уверенности, включая две короткие новые реплики, рекомендованные к дополнительному прослушиванию.

`python tools/chronicles/import_project.py` — одноразовый повторный импорт исходной V15.1; он пересоздаёт мастер и не предназначен для запуска поверх ручного монтажа. В дальнейшем редактировать нужно мастер проекта. Исходные V15/V15.1 не менялись.

Для новой редакции речи после сохранения монтажа использовать `tools/chronicles/sync_voice.py --manifest`, отдельно генератор озвучки, затем `sync_voice.py --apply-cache`. Полученный соседний Markdown импортируется в редактор. Ручная постановка сохраняется; сдвиг последующих фиксированных точек включается только явным `--ripple`. Подробные команды — в `tools/chronicles/VOICE_SYNC.md`. Эти операции сами не запускают платный синтез.

Из `repo/`: `npm run typecheck`; `node --test src/chronicles/*.test.mjs`; `npm run build`. Производственная сборка отклоняет отсутствующую/устаревшую озвучку, неверные слова выравнивания, отсутствующие файлы и неразрешённые якоря. `npm run build:candidate` явно разрешает предварительный просмотр недостающей озвучки и обновляет только `repo/dist`; обычная сборка обновляет `game.html` после копирования ресурсов. `game-previous.html` сохраняется.

Материалы проверки: `media/interactive/chronicles/import-report.json`, `voice-recovery-verification.json`, `context-assets.json`, `neutral-portraits.json`, `repo/src/chronicles/build-manifest.json`. Визуальные источники и кропы описаны в `PORTRAIT_REVEAL_QA.md`; исходники в `Fin` не изменялись.

## Совместимость с прежним плеером после исправлений

Восстановлена исходная 45,5-секундная заставка: дисклеймер, звёздное видео, Playbox / Studios / Presents, основной логотип и цикл. Никакого описания пяти залов перед началом: только прежняя кнопка «Начать просмотр». После передачи слова Толе остаётся только кнопка «Продолжить». Стиль кнопок и субтитров взят из исходных MovieApp / Subtitles.

Заставка хранится как сцена `OPENING`, её параметры — в `opening`, музыка — обычный клип A2. Во вкладке «Клип» без выделенного клипа редактируется её конфиг. Вкладка «Музыка» возвращает выбор Desolate Cry / Titan Forge, списки нагнетания и передышки, стоп/fade, выбор звука перехода, JSON музыки и сброс к состоянию открытого файла. В режиссёре T/P/X ставят cue, [ / ] сдвигают выбранный музыкальный клип на секунду. Все эти правки проходят через общую историю и сохраняются Ctrl+S в Markdown. В обычном просмотре T меняет вариант музыки заставки, P перематывает её на 24 секунды.

Исходные пять оптических переходов длительностью 2,4 секунды задаются в `scene.transition`; их звук находится на A6. Смена кадра внутри сцены остаётся склейкой. Явная перемотка и монтажный просмотр сразу восстанавливают выбранный кадр без проигрывания старого перехода. Пауза фиксирует ход перехода.

Адреса наклеек сохранены в `navigation` с теми же привязками к сценам/репликам/словам, что клипы. Редактируются в «Маршрут → Наклейки навигации». Логотип ведёт в OPENING, наклейки вердикта и награды — в разные точки; награда привязана к VERDICT.P012. Перезапись голоса не превращает её в устаревшую секунду.

Субтитры держат целую фразу в паузах между словами. ⏮ / ⏭ используют те же границы фраз. В интерактиве перемотка ограничена текущей исполняемой веткой; она не перебирает невыбранные реакции и не подставляет ответ вместо D для открытия режиссёра. Ввод в текстовые поля сохраняет обычные клавиши ввода.

После аудиоаудита заменены шесть дефектных фрагментов. Текст всех 242 реплик остался утверждённым. Число 1783 передано сервису прописью по отдельному разрешению пользователя, но в мастер-тексте осталось цифрами. Отчёт: `media/interactive/chronicles/voice-quality-report.json`. ASR служит проверкой соответствия текста; полный художественный просмотр и сведение остаются отдельной задачей.


По уточнению 18.11 стартовая кнопка использует исходный стиль `.cinema-play-btn` опубликованного сайта. Панель показывается от мыши и на заставке; исключения — начальный экран, живая остановка и монтажный интерфейс. Перед прологом отдельный DREAD desolate_cry и случайный звуковой удар перехода убраны: музыка заставки уходит fade-out 2,5 с, затем только BASE rust_and_bone плавно входит за 2,5 с. Речь не перезаписывалась. Текущий мастер — 915 клипов.


Уточнение интерактивов: во всех пяти играх и COMMON фоном остаётся ИИ-Лорд. Фон — обычный клип V1 в каждой игровой сцене, доступный в инспекторе. Портреты героев и их именные плашки из игровых сцен убраны; сюжетные кадры обычных глав сохранены. Маскированные скриншоты и игровые элементы остаются во время вопроса/реакций. На завершении игры они исчезают, остаются Лорд и та же единственная кнопка «Продолжить», что на живой остановке. Кнопки «К хроникам» в плеере больше нет; первичные действия используют общий бирюзовый стиль сайта. Согласованные автоматические выходы после проигрыша не менялись.


Адаптивный показ: `clip.layout: "character"` включает исходную угловую карточку, `avatarAssetId` выбирает аватарку из реестра ресурсов, `typewriter` включает печать имени и титула при первом появлении. `layout: "screenshot"` вписывает скриншот в максимальную безопасную область, а в игре — в свободное место между вопросом и ответами. Режимы и аватарка доступны в инспекторе. Перемещение объекта либо изменение его геометрии переводит размещение в `manual`; непрозрачность не отключает автоматическую композицию. Все параметры сохраняются обычным Ctrl+S в тот же `chronicles-config`.

Клик по источнику открывает его в исходном масштабе с прокруткой, сохраняя маски; фильм продолжает воспроизведение после закрытия, если до открытия играл. Нейтральные портреты имеют дополнительные копии `*-identity.webp` без чёрного паспарту; это прежние согласованные вырезки без генерации нового содержания. `CharacterBadge.ts` и `presentation.css` воспроизводят исходную карточку MovieApp; `presentation.ts` содержит геометрию и печать. Нагнетающие/добрые cue используют прежнюю калибровку AmbientManager: нормирование к .85 и речевое приглушение .45. Автоматическое приглушение BASE остаётся отдельным.
