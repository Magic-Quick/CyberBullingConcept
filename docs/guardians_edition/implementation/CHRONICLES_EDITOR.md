# Хроники: фильм и режиссёрский монтаж

Реализовано 18.11.2026 на основе V15.1. Предыдущий код и материалы сохранены в GitHub: ветка `codex/backup-before-director-plan-20261118`, коммит `f11664f46abd1bc26a24d383a60600a63d53dd80`.

## Запуск

1. Из корня проекта запустить `tools/OPEN_CHRONICLES_DIRECTOR.bat`.
2. Редактор: <http://127.0.0.1:8877/repo/dist/index.html?director>. Просмотр: <http://127.0.0.1:8877/game.html>. В просмотре клавиша D/В или надпись WS-96 открывает режиссёра.
3. Выбрать сцену и при необходимости игровую ветку. Центральный экран использует тот же рендер, что фильм.
4. Сохранить через Ctrl+S. Надпись об успешной записи появляется только после подтверждения файла сервером.

Основной текстовый файл — `repo/src/chronicles/default-project.md`. Речь хранится один раз в блоках `[ГОЛОС ЛОРДА ID]`; единственная секция `chronicles-config` хранит ресурсы, дорожки, клипы, привязки, остановки, правила и ветки. Обычный Markdown до конфига остаётся читаемым сценарием. Редактор умеет открыть, применить и экспортировать весь Markdown.

При конфликте с внешним редактором запись отклоняется по версии. Сервер не перезаписывает чужие изменения. Если этот же файл открыт в Co-Writer, запись идёт через Hub API с `expectedVersion`, проверкой `editorVerified` и отдельным сохранением. История прежних файлов хранится в `scratch/chronicles-history/`.

## Монтаж

Доступны библиотека с поиском, предпросмотром и перетаскиванием, 12 дорожек, инспектор, выбор веток, масштаб и магнит, перемещение и обрезка клипов, сдвиг последующих клипов, несколько выделенных клипов, копирование, вставка, дубликат, удаление, undo/redo. На экране можно перетащить видимый объект; точные значения задаются справа.

- V1: кадр, положение, масштаб, поворот, прозрачность, кроп, fade и чистая экспозиция.
- V2: скриншот или другое изображение с отдельным началом и концом.
- V3/V4: имя, полный титул и экранный текст.
- T1: субтитры от речи либо отдельная редакция.
- A1–A6: голос, атмосфера, нагнетание, передышка, музыка игры и SFX; громкость, fade, source in/out, петля, огибающая и приглушение BASE.
- I1: остановки, маршрут, тема живого слова, вопрос, ответы, лимиты, реплики и переходы игры.

Space управляет воспроизведением вне текстового ввода. Ctrl+Z / Ctrl+Shift+Z — история. Речь редактируется в инспекторе: изменённый текст сразу помечает старую озвучку и словесные привязки устаревшими. Новая озвучка не генерируется без отдельного запуска пайплайна.

Якорь клипа может ссылаться на сцену, начало/конец реплики или конкретное выровненное слово. Сдвиг хранится рядом с якорем. Пауза останавливает монтажные часы; перемотка вычисляет слои заново. Чистая экспозиция кадра задаётся полем `cleanExposure`: плашки и скриншоты не закрывают его раньше указанного времени.

Библиотека использует ресурсы сборки. При добавлении новых файлов на диск их нужно включить в реестр ресурсов и пересобрать фильм; импорт Markdown сам по себе не копирует медиа на другой компьютер.

## Интерактивы и маршрут

Зрительский дизайн сохранён: исходная консоль WS-96, её текстуры, кнопки, ручки, LCD, тонкая шкала и наклейки. На ней у каждого из пяти залов две маленькие нейтральные метки: квадрат «Слово Толе» и ромб «Интерактив». Они показывают текущий этап, ожидание, прохождение и пропуск без названий ответов и сюжетных развязок. Живое слово и ответ зрителя ждут команды без фиктивной длительности и таймера поражения. Время шкалы относится к записанным главам; ожидание не растягивает шкалу.

I-04: четыре варианта и три различные ошибки. I-01: восемь букв. I-03: один окончательный содержательный ответ. I-02: один выбор и раскрытие всех четырёх пунктов. I-05: пять букв. COMMON.ЛИМИТ доступен только I-04/I-01/I-05. После реакции игра возвращается в единую историю. Маскированный контекст живёт на V2 до выхода в сюжет; увеличение открывает тот же подготовленный файл.

## Данные и сборка

Текущий мастер включает 242 речевых блока, 27 сцен, пять остановок и отдельный готовый музыкальный трек. 35 реплик использовали существующие записи, 207 озвучены Geremy через ElevenLabs с разрешения пользователя. Все 3587 слов имеют реальные временные границы; недостающие метаданные восстановлены локально без повторной генерации. В отчётах выравнивания сохранены показатели уверенности, включая две короткие новые реплики, рекомендованные к дополнительному прослушиванию.

`python tools/chronicles/import_project.py` — одноразовый повторный импорт исходной V15.1; он пересоздаёт мастер и не предназначен для запуска поверх ручного монтажа. В дальнейшем редактировать нужно мастер проекта. Исходные V15/V15.1 не менялись.

Для новой редакции речи после сохранения монтажа использовать `tools/chronicles/sync_voice.py --manifest`, отдельно генератор озвучки, затем `sync_voice.py --apply-cache`. Полученный соседний Markdown импортируется в редактор. Ручная постановка сохраняется; сдвиг последующих фиксированных точек включается только явным `--ripple`. Подробные команды — в `tools/chronicles/VOICE_SYNC.md`. Эти операции сами не запускают платный синтез.

Из `repo/`: `npm run typecheck`; `node --test src/chronicles/*.test.mjs`; `npm run build`. Производственная сборка отклоняет отсутствующую/устаревшую озвучку, неверные слова выравнивания, отсутствующие файлы и неразрешённые якоря. `npm run build:candidate` явно разрешает предварительный просмотр недостающей озвучки и обновляет только `repo/dist`; обычная сборка обновляет `game.html` после копирования ресурсов. `game-previous.html` сохраняется.

Материалы проверки: `media/interactive/chronicles/import-report.json`, `voice-recovery-verification.json`, `context-assets.json`, `neutral-portraits.json`, `repo/src/chronicles/build-manifest.json`. Визуальные источники и кропы описаны в `PORTRAIT_REVEAL_QA.md`; исходники в `Fin` не изменялись.
