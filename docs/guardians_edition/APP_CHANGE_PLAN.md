## 1. Обязательное поведение

- Диктор произносит короткие имена; полный титул и имя сохраняются в карточке персонажа.
- Представление персонажа идёт последовательно: чистый портрет → имя и полный титул → голос и субтитры.
- Для Supercell поддерживаются разные формы: «Сверхъячейка» в голосе, оригинальное Supercell в подписи; при явном выборе — также в тексте субтитров.
- Субтитры, именные карточки и Slack-попапы — независимые слои с собственными интервалами появления.
- Отключение субтитров не удаляет именную карточку.

## 3. Данные сцены и генерация

- [ ] Ввести версионированный формат с `entities`, `scenes`, `utterances`, `nameplates`. Поля и пример ниже являются проектом контракта.
- [ ] Каждая реплика получает устойчивый `id`, `voiceText`, опциональный `subtitleText`, `speakerId`, аудиоключ и временной интервал. `speakerId` обозначает звучащего рассказчика; человек, показанный на портрете, задаётся отдельно.
- [ ] `subtitleText: null` наследует `voiceText`; пустая строка считается ошибкой. Для скрытия текста использовать отдельную настройку видимости, а не неоднозначное пустое значение.
- [ ] Явное расхождение названия связывать с `entityId` и причиной. Дословные цитаты защищать от таких замен.
- [ ] Имя и титул карточки получать из сущности; карточка имеет отдельный интервал, без собственной произносимой реплики.
- [ ] Сначала синтезировать / выравнивать голос по `voiceText`, затем по тем же границам реплик ставить `subtitleText`. Оригинальное Supercell не используется для поиска звучащего слова «Сверхъячейки» в аудио.
- [ ] Поддержать тишину до начала реплики: отдельные аудиоклипы размещаются на таймлайне; при экспорте общей дорожки паузы действительно добавляются в звук. Сдвиг одних субтитров не создаёт представление персонажа.
- [ ] Участки внутри длинной реплики привязывать к выравниванию слов голоса. При необходимости разных визуальных событий делить реплику на осмысленные фрагменты с устойчивыми идентификаторами.
- [ ] Отклонять производственный экспорт с демонстрационными таймингами, неразрешёнными ключами ассетов или отсутствующей озвучкой. JSON-пример имеет статус `example_not_production`.

## 4. Интерактивный фильм: последовательность представления

Предлагаемые начальные настройки для предпросмотра, подлежащие монтажной проверке:

| Время от входа в сцену | Кадр | Карточка | Новая речь и субтитры |
| --- | --- | --- | --- |
| 0–3 с | Чистый портрет | Скрыта | Не начинаются |
| 3–7 с | Тот же портрет | Имя и полный титул | Не начинаются |
| С 7 с | Разрешённый монтаж | Может уйти или остаться ненавязчиво | Начинаются вместе |

Четыре секунды карточки в таблице предполагают сразу видимый текст. При печатной анимации время набора добавляется к интервалу карточки; голос ждёт завершения набора и чтения. Чистый показ остаётся в пределах согласованных 2–4 секунд. Длинные титулы должны полностью помещаться в кадре без обрезки.

- [ ] Разделить состояния `portrait`, `nameplate`, `speech` на одном таймлайне. Музыка и атмосфера могут продолжаться во время представления.
- [ ] Дождаться готовности портрета и звука до начала сцены. Задержка загрузки не сокращает чистую экспозицию и время чтения.
- [ ] Исключить преждевременный показ первого субтитра и растягивание предыдущей реплики на интервалы чистого кадра / карточки. Отдельно проверить существующую логику `Subtitles.syncToTime`, которая выбирает ближайшую реплику вне её точного интервала.
- [ ] Новое представление не должно запускать Slack-попап. Переписка появляется при соответствующей реплике, после чистой экспозиции.
- [ ] Пауза останавливает монтажное время; перемотка восстанавливает видимые слои и позицию звука по целевому времени. Не строить последовательность на независимых `setTimeout`.
- [ ] Полное представление использовать при первом знакомстве; политику повторов подобрать в предпросмотре. Переход через таймлайн и повтор сцены должны давать определённый результат без зависимости от случайного состояния сессии.
- [ ] Проверить названия глав и подсказки таймлайна на спойлеры.

Согласованное предварительное появление человека не распространяется на сюжетные предметы и события, в том числе фон портрета, раскрывающий последующую кару.

## 7. Критерии приёмки

- [ ] В голосовой экспорт не попадает «Палач Старого Стека» из карточки, но в карточке титул виден полностью.
- [ ] Голос произносит «Сверхъячейки»; оригинальное Supercell показано там, где явно задано автором.
- [ ] До начала речи нет её субтитров. Карточка успевает появиться и прочитаться; Slack не перекрывает вход портрета.
- [ ] Речь, субтитры и кадры остаются согласованными после паузы, перемотки назад / вперёд и повторного входа в сцену.
- [ ] Сцена понятна без чтения длинного титула; брутальность и фантастическое содержание сохранены.
- [ ] Старые сохранения и действующий выпуск открываются через прежний путь или явный адаптер; импорт не перезаписывает оригинал.
- [ ] Ключи `Fin` допускаются как источники для чтения; генераторы и экспорт не записывают файлы в `Fin`.
- [ ] При реализации выполнены `npm run typecheck`, `npm run build` и визуальная проверка пробных сцен. Фиксация этого плана не означает прохождение будущих проверок.
