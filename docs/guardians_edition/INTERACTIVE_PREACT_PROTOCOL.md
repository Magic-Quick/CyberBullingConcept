## Как выглядит

Перед запуском `act_3_timemachine` фильм останавливается. Сначала на 2,5 секунды открывается чистый кадр ИИ-Лорда. Затем появляются восемь классических синих квадратов с серебристой рамкой и вопрос: «Какое слово Горин произнёс на синке?».

Два режима: «Назвать букву» и «Слово целиком». Ввод с клавиатуры, подтверждение Enter или кнопкой «Проверить». Внизу — текущая реплика Лорда. Названные буквы остаются под табло; ошибочные зачёркнуты. Подсказки, названия и меню не содержат разгадку.

Правильное слово — **демоблил**, восемь букв. «Л» открывается одновременно в шестой и восьмой клетках. Можно открыть всё слово по буквам или ввести его целиком. Регистр и пробелы по краям не влияют на ответ. Ошибка не раскрывает слово и не запускает акт.

После разгадки команда видит слово полностью и нажимает «Продолжить акт». Только тогда начинается исходный третий акт. Вставка показывается один раз за просмотр; переход к началу фильма сбрасывает её прохождение.

## Реплики Лорда

| Событие | Реплика |
|---|---|
| Вступление | На синке Горин произнёс слово из восьми букв. Буквы знакомые. Сочетание авторское. Восстановите реплику, и я продолжу хроники. |
| Начало ввода буквы | Назовите одну букву. Начнём с того, что признаёт алфавит. |
| Правильная буква | Есть такая буква. Пока всё в пределах русского языка. |
| Неправильная буква | Нет такой буквы. Даже Горин обошёлся без неё. |
| Начало ввода слова целиком | Называйте слово целиком. Авторскую орфографию сохраняем. |
| Правильное слово или последняя открытая буква | Демоблил. Совершенно верно. Слово восстановлено. Русский язык пока нет. Продолжаем хроники. |
| Неправильное слово целиком | Нет. Редактировать Горина будем после расшифровки. Пока нужна точная версия. |
| Повторная буква | Эту букву уже проверяли. Повторный синк новых данных не добавит. |
| Латиница, цифра или знак | Одну русскую букву. Раскладку Горина сегодня не усложняем. |
| Неверная раскладка в режиме слова | Введите слово кириллицей. Диалект Горина и без того требует расшифровки. |
| Пустая попытка | Введите букву или слово. Молчание в протоколе не сохранилось. |

## Открыть и собрать

- Готовая автономная проба: `media/interactive/protocol-preview/interactive-preview.html`.
- Проба в dev-сервере: `http://127.0.0.1:5175/interactive-preview.html`.
- Фильм сразу с этой вставки: `http://127.0.0.1:5175/?preview=protocol`.
- Запуск сервера из `repo`: `node tools/start_interactive_preview.mjs`.
- Сборка автономной пробы из `repo`: `node tools/build_interactive_preview.mjs`.
- Проверка логики из корня: `node --experimental-strip-types --test tools/interactive/word_guess_model.test.mjs`.

Сервер и сборка используют `configLoader: native`, а кэш — внутри `scratch/`: установленная папка `node_modules` является общей и недоступна для записи в текущей песочнице.
