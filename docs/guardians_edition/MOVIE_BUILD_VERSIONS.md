Номера v1.0 / v2.0 относятся к сборкам фильма на сайте. Последний авторский текст — [V15](VOICES_OF_PRODUCTION_V15_GUARDIANS.md), его вариант с режиссёрскими вставками — [V15.1](VOICES_OF_PRODUCTION_V15_1_GUARDIANS.md). Эти сценарные редакции сохраняют свои номера; в текущей v2.0 перенесены все пять залов, передачи слова и игровые ветки. Новая редакция сценария не меняет названия переключателя v1.0 / v2.0.

Обычная сборка `npm run build` из `repo` обновляет только `game.html`. Файл `game-previous.html` не пересобирается и не подменяется вариантом текущего кода. Общие ресурсы имеют имена с хешами; прежние файлы остаются доступными.

## Плеер обновлённой версии

Текущая v2.0 исполняет `repo/src/chronicles/default-project.md`. Сохранены исходная консоль WS-96, заставка, шрифты и хоткеи. Кнопка начала использует бирюзовый прямоугольный стиль `.cinema-play-btn` с сайта; живая остановка показывает только «Продолжить». Нижняя панель появляется от движения мыши и во время заставки, прячется после 2,5 секунды бездействия, остаётся видимой при паузе и наведении на элементы управления.

В `index.html` ровно две кнопки: v2.0 — `game.html`, v1.0 — `game-previous.html`. `game-v2-before-director.html` сохраняется как техническая резервная копия до переноса, дополнительной кнопкой не становится. Полное устройство актуального монтажа: [CHRONICLES_EDITOR.md](implementation/CHRONICLES_EDITOR.md).

Публичный сайт обновляется workflow `.github/workflows/deploy.yml` только после push в `origin/master`. Сохранение билда в локальном файле или push резервной ветки сами по себе сайт не обновляют. Последний такой пропуск обнаружен 18.11: на публичном сайте оставался коммит `4a364d9` от 07.11 без переключателя, хотя локальная страница уже содержала его. Перед завершением публикации нужно дождаться успешного Pages deployment и проверить сам публичный адрес.

## Локальный просмотр с перемоткой

Из корня проекта:

```powershell
tools\START_PRESENTATION_SERVER.bat
# или:
python tools/interactive/serve_presentation.py --port 8876
```

Открыть `http://127.0.0.1:8876/index.html#playable-area`. Сервер поддерживает HTTP byte ranges, необходимые браузеру для перемотки аудио; он слушает только `127.0.0.1`. Простая раздача файлов без поддержки диапазонов может сбрасывать позицию звука в начало.

Проверки: `python tools/interactive/test_presentation_server.py`, а также `node --experimental-strip-types --test tools/interactive/word_guess_model.test.mjs tools/interactive/word_guess_captions.test.mjs tools/interactive/word_guess_placement.test.mjs`.

## Запуск через DEV-батник

`tools/START_MOVIE_DEV.bat` и `tools/OPEN_INTERACTIVE_MOVIE.bat` запускают одну текущую версию из `repo/src` на `http://localhost:5174/`. Предыдущая сборка в DEV не подставляется. Прямой вход к игровой вставке для проверки: `http://localhost:5174/?preview=protocol`.

Браузер открывает сам Vite после успешного запуска сервера. При занятом порте запуск завершается с ошибкой, без автоматического переезда на 5175 и открытия другого сервера. Кэш Vite находится в проектном `scratch/movie-vite-cache`, конфигурация загружается через `--configLoader native`.

Переключение текущего и предыдущего фильма остаётся на странице презентации `http://127.0.0.1:8876/index.html#playable-area`.
