При переключении старый iframe удаляется целиком. Одновременно работает один плеер; звук и таймеры предыдущего документа прекращаются. Повторное нажатие на уже выбранную версию не перезапускает просмотр. Прямая ссылка внизу страницы следует выбранной версии.

Выбор предыдущей версии сохраняется в адресе: `index.html?film=previous#playable-area`. Адрес обновлённой версии: `index.html#playable-area`.

Обычная сборка `npm run build` из `repo` обновляет только `game.html`. Файл `game-previous.html` не пересобирается и не подменяется вариантом текущего кода. Общие ресурсы имеют имена с хешами; прежние файлы остаются доступными.

## Плеер обновлённой версии

Вставка использует штатные нижние субтитры `Subtitles.ts`, переключатель CC и панель WS-68. Пауза останавливает её голос и музыку. Кнопки предыдущей/следующей фразы перематывают текущую реплику Лорда с сохранением паузы. Первое открытие третьего акта через главу или общий таймлайн сначала показывает игру. Последующее действие ползунком закрывает вставку вместе с её аудио и выбирает место самого фильма. Позиция вставки на общем таймлайне соответствует началу третьего акта: сначала угадывание, затем акт с Горином с нулевой секунды, и уже в нём — реплика с ответом.

Размеры и шрифты вопроса, контекста, кнопок и букв передаются из существующих текстовых объектов фильма. Отдельная типографическая шкала не задаётся.

## Локальный просмотр с перемоткой

Из корня проекта:

```powershell
tools\START_PRESENTATION_SERVER.bat
# или:
python tools/interactive/serve_presentation.py --port 8876
```

Открыть `http://127.0.0.1:8876/index.html#playable-area`. Сервер поддерживает HTTP byte ranges, необходимые браузеру для перемотки аудио; он слушает только `127.0.0.1`. Простая раздача файлов без поддержки диапазонов может сбрасывать позицию звука в начало.

Проверки: `python tools/interactive/test_presentation_server.py`, а также `node --experimental-strip-types --test tools/interactive/word_guess_model.test.mjs tools/interactive/word_guess_captions.test.mjs tools/interactive/word_guess_placement.test.mjs`.

## Запуск через DEV-батник

`tools/START_MOVIE_DEV.bat` и `tools/OPEN_INTERACTIVE_MOVIE.bat` запускают одну текущую версию из `repo/src` на `http://localhost:5174/`. Предыдущая сборка в DEV не подставляется. Прямой вход к игровой вставке для проверки: `http://localhost:5174/?preview=protocol`.

Браузер открывает сам Vite после успешного запуска сервера. При занятом порте запуск завершается с ошибкой, без автоматического переезда на 5175 и открытия другого сервера. Кэш Vite находится в проектном `scratch/movie-vite-cache`, конфигурация загружается через `--configLoader native`.

Переключение текущего и предыдущего фильма остаётся на странице презентации `http://127.0.0.1:8876/index.html#playable-area`.
