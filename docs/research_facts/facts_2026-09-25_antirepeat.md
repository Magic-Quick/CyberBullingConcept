## 4. Структура и длительности эталона v3 (lines_2026-09-18e.json)

### Порядок ключей (как в файле)
`intro` → `rules` → `hero:<key>` ×10 (ростер) → для каждого зала `hN_in` → `dash:<id>` → `hN_out` → `verdict` → `epilogue` → `batch:<имя батча>` (▶ в карточках красных батчей).
Залы v3 — пять, не шесть: h1 Кузня (`dash:overview`), h2 Камера застрявших (`dash:red`), h3 Хранилище наград (`dash:green`), h4 Чистилище (`dash:yellow_other`), h5 Башня времени (`dash:month`). Тронный зал = `verdict`.
Типы значений: `intro`, `rules`, `hN_in`, `hN_out`, `verdict`, `epilogue` — массив ровно из 3 битов; `hero:*`, `dash:*`, `batch:*` — одна строка.
Ключи героев — латиницей, коротко: eduard, eva, khukhro, damir, mamusin, kramnoi, vika, rubin, pankov, pavel. Батчи — точное имя из данных (`batch:Freecash Batch 4 / Mintegral`).

### Кадры (scenes_2026-09-18g.json)
Список объектов `{name, cast, prompt, easter?, style?}`; `name` = `<ключ>_<номер бита>` (intro_1…3, h2_out_3, verdict_2 и т.п.) — по одному кадру на каждый бит массивных ключей (итого 42 кадра). `cast` — ключи персонажей из листа персонажей или `lord`, пустой `[]` = безымянная команда; `style: "explainer"` у rules_1…3; `easter` — мелкая пасхалка клиента. У `hero:*`, `dash:*`, `batch:*` кадров нет (аватар / дашборд).

|---|---|---|---|---|
